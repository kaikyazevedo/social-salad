# Instruções para agentes de código — Social Salad

- Leia PROJECT.md antes de qualquer edição.
- Produto pessoal para organizar clientes e projetos; NÃO implementar checkout, contratos ou propostas comerciais sem pedido explícito.
- Não tocar em THAC Production OS, suas contas, suas chaves ou dados.
- Prioridade absoluta: layout mobile-first e navegabilidade com uma mão.
- Manter identidade preto/rosa/amarelo/editorial.
- Não colocar dados reais de clientes em previews, código, commits ou logs.
- Alterar apenas o necessário e validar build antes de publicar.
- Ao preparar Supabase, usar projeto próprio, autenticação e RLS por usuário/workspace.
- Não apresentar demo como painel seguro. Todas as demonstrações devem conter apenas dados fictícios.
- Fazer mudanças pequenas, reversíveis e fáceis de revisar.
